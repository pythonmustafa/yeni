# Kurumsal Yönetim Paneli

Bu proje, şirket içi cari hesapları yönetmek için geliştirilmiş bir Full-Stack web uygulamasıdır.

## Kullanılan Teknolojiler
* **Frontend:** React.js (Vite), Material-UI (MUI)
* **Backend:** Node.js, Express.js
* **Veritabanı:** PostgreSQL (Supabase)
* **Dağıtım (Deploy):** Render.com

## Kurulum
Projeyi kendi bilgisayarınızda çalıştırmak için:
1. Depoyu klonlayın.
2. Ana dizinde `npm install` komutunu çalıştırın.
3. `client` klasörüne girip `npm install` komutunu çalıştırın.
4. Ana dizinde `.env` dosyası oluşturup Supabase API anahtarlarınızı girin.
5. Ana dizinde `npm start` yazarak projeyi başlatın.
